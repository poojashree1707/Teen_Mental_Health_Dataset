# Project Title
## Teen Mental Health Analysis

# Project Description
## This project analyzes teen mental health data to understand factors affecting emotional well-being such as stress, anxiety, academic pressure, sleep habits, social media usage, and lifestyle patterns.

# Purpose
## The purpose of this project is to identify mental health challenges faced by teenagers and analyze the factors influencing their mental well-being. The project aims to create awareness and support data-driven understanding of teen mental health.

# Conclusion
## This project helped analyze the important factors affecting teen mental health. By studying stress levels, sleep patterns, social media usage, academic pressure, and emotional well-being, meaningful insights were identified. The analysis shows that mental health is influenced by both lifestyle and environmental factors. This project can help create awareness about teenage mental health and support better understanding for early care and support systems.
